# العربي ↔ الفرانكو (Arabic ↔ Franco)

أداة ويب صغيرة لتحويل النص بين **العربية** و**الفرانكو** (كتابة الكلام العربي بحروف لاتينية وأرقام زي `3` و`7` و`6`).

الموقع شغال بالكامل جوه المتصفح: مفيش سيرفر، مفيش قاعدة بيانات، ومفيش أي طلبات خارجية.

## 🌐 جرّبه دلوقتي

**[https://el3ssal.github.io/arabic-franco/](https://el3ssal.github.io/arabic-franco/)**

## ✨ المميزات

- **تحويل فوري أثناء الكتابة** مع اكتشاف تلقائي للغة: عربي ← فرانكو أو فرانكو ← عربي.
- **قاموس جاهز** لأشهر الكلمات والجمل المصرية (`عايز` → `3ayez`، `ازيك` → `ezayak`، `ماشي` → `mashy` إلخ).
- **قواعد نطق** للحروف اللي مالهاش مقابل مباشر: `ع = 3`، `ح = 7`، `ط = 6`، `ص = 9`، `ش = sh / 4`، `غ = 3'`، `خ = 5`، `ق = 8`.
- أزرار **لصق / مسح / نسخ النتيجة** مع عدّاد للأحرف والكلمات.
- **وضع فاتح وداكن** + تبديل بين الواجهة العربية والإنجليزية، والتفضيلات محفوظة في `localStorage`.
- تصميم **متجاوب** يشتغل على الموبايل والكمبيوتر.

## 🛠️ التقنيات

ملف واحد `index.html` فيه الـ HTML والـ CSS والـ JavaScript مدمجين. مفيش dependencies ولا build step.

## ▶️ التشغيل محلياً

افتح `index.html` في المتصفح مباشرة، أو شغّل سيرفر بسيط:

```bash
python -m http.server 8000
# بعدين افتح http://localhost:8000
```
